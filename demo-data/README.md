# Demo Data — Test Files for Resonantia

Sample files for testing every workflow locally. Upload these via the chat interface (paperclip icon) or reference them in prompts.

## Files

| File | Use Case | What to Test |
|------|----------|-------------|
| `dose_response_staurosporine_HEK293T.csv` | **Killer workflow** (DAT/01) | Upload → "Fit dose-response curves" → IC50 ~42 nM for staurosporine. 240 rows, 8 compounds, 10 concentrations, 3 replicates. |
| `dose-response.csv` | Quick dose-response test | Minimal 8-row file. "Fit dose-response curve for this data" |
| `plate-reader-96well-controls.csv` | **Plate normalization** (DAT/02) | Upload → "Normalize this plate using Z-score with wells A1-B2 as positive controls and A12-D12 as negative" |
| `qpcr-ct-values.csv` | **qPCR analysis** (DAT/03) | Upload → "Run delta-delta Ct analysis using GAPDH as reference gene and Untreated as control" |
| `qpcr-multiplex-experiment.csv` | Extended qPCR test | 4 conditions, 6 genes, 3 replicates. "Analyze this qPCR experiment — which genes are upregulated by staurosporine?" |
| `compound-hit-list.csv` | **Cherry-pick** (PLT/01) | Upload → "Cherry-pick all compounds with Potency_Class=potent into a 384-well confirmation plate" |
| `sample-inventory-import.csv` | **Inventory** (INV/01) | Upload → "Import these samples into inventory" or "Which of these samples are expiring soon?" |
| `protocol-western-blot.csv` | **Protocol** (PRO/01) | Upload → "Create a protocol from this CSV" or "Do we have all the reagents listed here?" |
| `eln-experiment-results.csv` | **ELN** (ELN/01) | Upload → "Create an ELN entry summarizing experiment EXP-2026-001" |
| `microscopy-sample-DAPI-GFP.png` | **Image attachment test** | Attach in chat → "What cells do you see in this image?" (tests multimodal vision) |

## Quick Test Script

```
1. Upload dose_response_staurosporine_HEK293T.csv → "Fit all curves"
2. "Create an ELN entry from these results"  → Confirm approval card
3. Upload compound-hit-list.csv → "Cherry-pick the potent hits"  → Confirm
4. "Generate an Echo worklist"  → Confirm (amber warning)
5. Upload qpcr-multiplex-experiment.csv → "Which genes changed most at 1 µM?"
6. "What samples are expiring soon?" (uses demo inventory data)
7. "Calculate dilution: 10 mM stock to 100 µM in 500 µL"
8. Attach microscopy-sample-DAPI-GFP.png → "Describe this image"
```
